# 240 — Deal Check index: lookup shards built at publish (ships off)

## Why

Plan 2026-10-16 (research workflow; report in the operator's status page): a
free multi-store "Is this a good deal?" tool at /check/. A shopper pastes a
product link; the browser finds the product in small static files built at
publish and shows only prices we already verified, with dates. 0 Keepa tokens,
0 LLM calls, 0 retailer requests at lookup time. This task builds the data
side only (the page is task 241).

Policy findings that shape the data (do not weaken):
- Amazon Associates policy: prices only from an Amazon-served link or Amazon's
  API, and "your Site must not have price tracking and/or price alerting
  functionality" unless Amazon agrees. So the tool adds NO Amazon price number,
  history, verdict or watch: Amazon entries are link-only.
- Walmart's affiliate agreement bans price tracking/alerts for Walmart products:
  live verified deal only, no history, no ended entries.
- eBay listings end: live only.
- Best Buy, Target, Woot and other stores: live deal plus our own dated history.

## Task

1. Config `checker:` in config.yaml, validated in config.py:
   - `enabled: false` (shipped off; off = no files, byte-identical site);
   - `stores:` policy per store key: `amazon: link_only`, `walmart: live_only`,
     `ebay: live_only`, `bestbuy: history`, `target: history`, `woot: history`,
     `other: history` (allowed values exactly these three);
   - `ended_days: 90` (int 1..365), `shards: 256` (power of two, 16..1024).
2. `dealradar/publish/checker.py`:
   - `aliases(url) -> list[str]`: product keys from a URL, reusing existing
     helpers: Amazon ASIN (`amazon:<ASIN>`), Best Buy skuId, eBay `/itm/<id>`,
     Walmart `/ip/<id>`, Woot offer slug, Target `/A-<tcin>`, else the
     canonical URL (`url:<canonical>`). Store key from the host. Pure function.
   - `build(...)` → alias → entry, from:
     (a) public, unlocked, alive, evidence-verified deals as the site already
         publishes them (never locked/teaser/members-only, never
         `price_unconfirmed`, never flagged/suspect);
     (b) product_pages models: `/p/` path, check count, first-check date and
         the verdict sentence exactly as `product_pages.answer()` returns it;
     (c) for `history` stores only: last verified price and date of ended
         offers within `ended_days`.
   - Plain-price rule: a price that needs a code, clip coupon, membership,
     in-cart/in-store, multi-buy, rebate or gift card is shown as the deal but
     never used as "the last verified price" or in a verdict.
   - Entry fields: `kind` (live|ended), `store`, `item`, `price`, `at` (ISO
     UTC), `deal_path`, `p_path`, `verdict`, `checks`, `since`, `credit`.
     `link_only` entries carry only `kind`, `store`, `item`, `at`, `deal_path`
     (no price). `live_only` entries never have `ended`, `verdict`, `checks`,
     `since` or `p_path`.
   - Write `site/check/data/<xx>.json` (shard = first hex chars of
     sha256(alias), `shards` buckets), sorted keys, compact JSON, byte-identical
     on rerun; plus `site/check/data/meta.json` (generated_at from the publish
     time, counts by store and kind, policy map). Every shard < 64 KB; if one
     would exceed it, drop the oldest `ended` entries first and count them.
   - Call it from the publish path after product pages, only when enabled.
3. `robots.txt` Disallow `/check/data/` and `_headers` `X-Robots-Tag: noindex`
   for `/check/data/*` (only when enabled).
4. Run summary (private): `checker: {aliases, live, ended, link_only,
   dropped_ended, shards, bytes}`. No public field elsewhere.
5. Export the alias rules for the page: `checker.js_rules()` returns the
   regexes/host map as JSON-safe data so task 241 renders them into the page
   from Python (single source of truth), plus
   `tests/fixtures/checker_aliases.json` (URL → aliases, generated by Python
   from realistic URLs for every store incl. tracking params, mobile hosts,
   short links → no alias).

## Tests (offline, tests/test_checker_index.py)

- Disabled (default): no /check/ files; every published byte equals today's.
- Enabled: shards exist; no shard ever contains a locked, members-only,
  unconfirmed or flagged price; Amazon entries never contain `price`,
  `verdict`, `checks`, `since`, `p_path` or `ended`; Walmart and eBay entries
  never contain `ended`/`verdict`/history fields; `amazon_history: hide`
  respected.
- Plain-price rule: a code-only price never becomes an ended "last verified
  price" or feeds a verdict.
- Verdict text equals `product_pages.answer()` output exactly (no new math).
- Rerun: same run key twice → identical shard bytes, no new DB rows, no sends
  (extend test_rerun_is_idempotent, do not weaken it).
- Shard size cap and oldest-ended drop; deterministic order.
- Alias fixture: Python `aliases()` matches every fixture row.
