# Task 326 — "All discounts" must work when the search field holds an Amazon link (operator-approved 2026-10-19 ~13:35Z)

Read CLAUDE.md first. This tree is the live release 0b22b69. Operator: "When I enter a URL and I click All discounts, it doesn't take me to anything related to the URL ... when I actually search the name, then it comes up correctly." Screenshots: docs/codex-tasks/326-369.webp (field holds https://www.amazon.com/Nulaxy-Adjustable-Anti-Slip-Smartphone-Essenti...), 326-370.webp (Amazon's generic deals page opened). Cause: dealradar/publish/all_discounts.py search_script() — searchAmazonQuery() returns "" for links, so discounts falls back to `https://www.amazon.com/deals?tag=...`.

## Do (behind ONE new strict-bool flag `discounts_from_link` — dealradar/config.py default False = previous bytes byte-for-byte; config.yaml true quoting the operator)
When the All discounts button (desktop pill and the phone button) is pressed and the field holds an Amazon product link:
1. If the link path carries a product-name slug before `/dp/` or `/gp/product/` (e.g. `/Nulaxy-Adjustable-Anti-Slip-Smartphone-Essentials/dp/B0...`), turn it into words ("Nulaxy Adjustable Anti Slip Smartphone Essentials"; decode %xx, hyphens/underscores → spaces, drop pure ASIN/ref tokens, cap to ~8 words / 100 chars) and open the same All-discounts URL as for typed words: `https://www.amazon.com/s?k=<words>&rh=p_n_deal_type%3A23566065011&tag=<tag>`. Same sanitising and adult-word rule as typed queries (adult words → the generic deals page as today).
2. If the link has no name slug (amazon.com/dp/ASIN, /gp/product/ASIN, a.co/…, amzn.to/…): if the Analyze result already on the page has that product's title (same ASIN), use the title's words as in 1; otherwise open that product's own page `https://www.amazon.com/dp/<ASIN>?tag=<tag>` (short links a.co/amzn.to without an ASIN: open the generic deals page as today — never fetch/expand the short link).
3. Non-Amazon links keep today's behaviour. Typed words, the purple Analyze, the big Amazon button and every other link stay exactly as today. No Keepa calls, no network calls, no new UI.
